# Treechat plugins for Claude Code

```
/plugin marketplace add Knovigator/treechat-plugins
```

| Plugin | What it does | Install |
| --- | --- | --- |
| [treechat-ai](plugins/treechat-ai) | Image, video, lip-sync, music, voice and 4K-upscale models from [Treechat AI](https://treechat.com), run on your own Treechat account within spending caps you set. Every run is quoted first and waits for your yes. | `/plugin install treechat-ai@treechat` |
| [sceneboard](plugins/sceneboard) | A scene-by-scene review board for AI films, on claude.ai Artifacts. You comment on a scene, an agent fixes it and publishes the new clip back to its card. Uses treechat-ai for models, or your own. | `/plugin install sceneboard@treechat` |

Treechat AI sign-in: after installing, run `/mcp`, pick **treechat**, and authenticate in the browser.
